Secure member access

Member Login

Member accounts must be served through HTTPS. The login endpoint should create a secure server-side session cookie; passwords and session tokens should not be stored in this page.

Security boundary

HTTPS required

The browser page checks the current protocol before allowing login. On deployment, the host should also force HTTPS and send HSTS headers.

  • Use a backend login endpoint over HTTPS.
  • Set session cookies with Secure, HttpOnly, and SameSite protections.
  • Do not return long-lived session tokens to JavaScript.
  • Keep password reset and account recovery behind the same HTTPS boundary.
